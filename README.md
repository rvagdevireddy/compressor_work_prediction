# compressor_work_prediction
What is this project?
Standard air conditioners are "dumb." They set the Evaporation Temperature ($T_e$) to a single, cold baseline to guarantee the room gets cool, regardless of what the weather is like outside. This brute-force approach wastes a massive amount of electricity.This project is a Smart Optimizer that acts as a brain for the AC. Instead of using a fixed temperature, it constantly asks: "What is the absolute most efficient $T_e$ we can use right now without sacrificing comfort or breaking the machine?"
